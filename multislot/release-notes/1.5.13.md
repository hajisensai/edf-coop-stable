# EDF6MultiSlot 1.5.13

## English

- **Less stutter:** log lines no longer open, write and close the log file on the game's own threads. They are queued and written in batches by a writer thread; crash reports and the shutdown line are still written at once.
- **Less EOS work:** with `NetLog=1` the EOS SDK log level is raised only for the seven categories the log keeps (lobby, P2P, voice chat, ...), not for all of them. The log content is unchanged.
- **10- and 12-player builds:** each is a room family of its own (`SEARCH_TYPE` centres 0x6E and 0x6A). Only the same build lists or joins those rooms; the 8-player build is unchanged and still plays with 1.5.5+ players. With the setting OFF a larger build lists normal rooms only; turn it ON (F2) to find 10/12-player rooms. Enemy counts stop growing at eight players (x1.8).
- **Fix for rooms above eight:** the user-slot diagnostics held eight slots, which silently disabled `HandshakeRecovery` in a larger room.

## 中文

- **减少卡顿**：写日志不再在游戏线程上逐行打开、写入、关闭文件，改为先放进队列、由写线程批量写出；崩溃报告和退出时的最后一行仍当场写。
- **减少 EOS 开销**：`NetLog=1` 时只对会写进日志的 7 个类别（大厅、P2P、语音等）提高 EOS SDK 日志级别，不再全部提高；日志内容不变。
- **10 人版、12 人版**：各自是独立的房间族（`SEARCH_TYPE` 中心值 0x6E、0x6A），只有同版本能看到、能加入；8 人版不变，仍和 1.5.5 以后的 8 人版互通。大房间版关闭时房间列表只显示普通房，找 10/12 人房要先按 F2 打开。敌人数量到 8 人（1.8 倍）为止。
- **8 人以上房间的修复**：用户槽诊断原来只放得下 8 个，大房间里 `HandshakeRecovery` 会静默失效。

## 日本語

・重さ対策：ログの書き込みをゲームの処理から切り離しました。
  これまではログを1行書くたびに、ゲームの画面処理や EOS（通信）の処理の中で
  ファイルを開いて・書いて・閉じていました（2MB を超えると 1.5MB のコピーもその場で）。
  今はメモリにためて、別のスレッドがまとめて書きます（遅くても 0.2 秒ごと）。
  落ちたときの記録は、これまでどおりその場で書き出します。
・重さ対策：NetLog=1 のとき、EOS の全カテゴリを詳細（Info）にしていたのを、
  ログに残す7カテゴリ（ロビー・P2P・ボイスチャット など）だけにしました。ログの内容は同じです。
・10人版・12人版を追加しました（名前の最後が -10p / -12p のパッケージ）。
  - 10人版の部屋には 10人版の人だけ、12人版の部屋には 12人版の人だけが入れます。
    8人版とは部屋が互いに見えません（全員が同じ版をそろえてください）。
  - 10人版・12人版で 10人部屋・12人部屋を探すときは、部屋検索の前に F2 で ON にしてください。
    OFF のときの部屋検索には、通常の4人部屋だけが出ます（入れない 8人部屋は出しません）。
  - 敵の数は 8人のとき（1.8倍）で止まり、9人以上でも増えません（ホストの負担を抑えるため）。
  - 9人以上のオンラインは、まだ実機で確かめていません。
・8人版の部屋の仕組みは変えていません。1.5.5 以降の 8人版の人とも互いに部屋が見え、参加できます。
