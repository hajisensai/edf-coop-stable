## 安装

1. 下载下面的 **`EDF6DirectNet-v0.3.1.zip`**，完整解压到任意位置
2. 双击 **`INSTALL.bat`**（自动找到 Steam 里的 EDF6；没有 EDFModLoader 会顺便装上官方版）
3. 从 Steam 正常启动游戏

从 0.3.0 / 0.2.0 升级：直接重新运行 INSTALL.bat，原来的设置文件保留。**建议所有玩家都升级**，尤其是开公网直连的房主。

## 0.3.1 修复

| | |
|---|---|
| **IPv6 直连连不上** | 房主回包的源地址常常不是公布的那个 IPv6 地址（Windows 优先用临时地址），加入者会把房主的应答丢掉，直连一直建不起来。现在按会话识别房主的包。 |
| **直连可以被冒名顶替** | 知道房主地址和某玩家 EOS ID 的人能接管该玩家的直连。现在玩家在线时，来自其他地址的冒名连接一律忽略。直连成员数也加了上限。 |
| 房主直连静默失效 | 房主先进过别人的房间再自己开房时，直连可能忽略所有加入者 |
| 游戏卡顿 | 自动直连切换房主地址（尤其是域名地址）时可能卡住游戏线程几秒 |
| 偶发崩溃隐患 | 建房/进房回调在 EOS 重试时访问已释放的内存；插件加载瞬间有极小概率空指针调用 |
| UPnP | 不再删掉路由器上属于局域网其他设备的同端口映射 |
| 安装 | Steam 库在中文路径下时 INSTALL.bat 找不到游戏；没解压就双击会给出提示 |
| 说明书 | 重写。注意：**房主设了 `Key=`，每个加入者都要填一样的 Key**，否则自动直连失败（回落到 Epic）。 |
