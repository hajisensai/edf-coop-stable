## 安装

1. 下载下面的 **`EDF6DirectNet-v0.3.2.zip`**，完整解压到任意位置
2. 双击 **`INSTALL.bat`**（自动找到 Steam 里的 EDF6；没有 EDFModLoader 会顺便装上官方版）
3. 从 Steam 正常启动游戏

从旧版升级：直接重新运行 INSTALL.bat，原来的设置文件保留。**房主和加入的人都要升级**，这个修复需要双方都是 0.3.2。

## 0.3.2 修复

| | |
|---|---|
| **进房后不自动直连** | 实际联机日志显示：加入的人读不到房主早先写进房间的直连地址，自动直连从未发起（全程走 Epic）。房间里已有成员的插件信息，只有在它再次变化时才会同步给新进来的人。现在有人进房时，房间里每个装了插件的人都会重新发布一次，新成员马上就能读到房主地址和各人的插件标记。 |
| 掉线不重来对「先进房的人」不生效 | 同一原因：新进来的人看不到老成员的插件标记，会把老成员当成没装插件。已随上一条一起修复。 |
| 诊断 | 加入的人进房 6 秒后仍读不到房主地址时，日志写一行 `DIRECT room host … advertises no direct-link address (…)`，说明看到了什么，方便继续排查。 |
