## English

### Install

1. Download **`EDF6DirectNet-v0.3.3.zip`** below and extract all of it anywhere
2. Double-click **`INSTALL.bat`** (finds EDF6 in your Steam library; installs the official EDFModLoader if you have none)
3. Start the game from Steam as usual

Upgrading: just run the new INSTALL.bat; your settings file is kept. Online behaviour is the same as 0.3.2, so 0.3.2 and 0.3.3 players can play together.

### What's new in 0.3.3

- **Chinese / Japanese / English**: the zip has a readme in each language (`README_EDF6DirectNet.txt` / `_ja.txt` / `_en.txt`); installer messages and the comments of the settings file created on first start follow the Windows display language (Chinese, Japanese, otherwise English). An existing settings file is not touched.
- The project README is available in all three languages.
