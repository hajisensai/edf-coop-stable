## Install

1. Download **`EDF6DirectNet-v0.3.4.zip`** below and extract all of it anywhere
2. Double-click **`INSTALL.bat`** (finds EDF6 in your Steam library; installs the official EDFModLoader if you have none)
3. Start the game from Steam as usual

Upgrading: just run the new INSTALL.bat; your settings file is kept. **Everyone in the room should upgrade**: each player's plugin decides what its own game is told.

## What's new in 0.3.4

Found in a real four-player session: a player whose direct link was working fine was pushed out of the room twice, because Epic's lobby service briefly lost that player and every game in the room removed them at once.

- **Epic's lobby service can no longer drop a player whose direct link works.** When it reports someone as disconnected while their direct link still answers, the game is not told; when Epic lets them back into the room, the game never sees any of it. The game hears about it only once the direct link has been silent for `GraceSeconds` (30 s), or the player leaves or is kicked for real. This also covers yourself.
- **Direct-link players are judged by the direct link's heartbeat**, not by recent game traffic: in menus the game sends almost nothing, so Epic connection drops there used to reach the game after 30 s even with a perfectly good direct link.
- **Plugin facts no longer vanish**: a joiner's copy of the room was seen losing the host's plugin marker and address a few seconds after joining. What the plugin learnt about a member now stays valid until that member leaves.
- **Diagnostics**: every time the game removes a player from the room, the log records whether the direct link still showed that player playing (`GAME kicks ...`).

## 中文

### 安装

1. 下载下面的 **`EDF6DirectNet-v0.3.4.zip`**，完整解压到任意位置
2. 双击 **`INSTALL.bat`**（自动找到 Steam 里的 EDF6；没有 EDFModLoader 会顺便装上官方版）
3. 从 Steam 正常启动游戏

从旧版升级：直接重新运行 INSTALL.bat，原来的设置文件保留。**房间里所有人都要升级**：每个人的插件只管自己的游戏知道什么。

### 0.3.4 更新

来自一次真实的四人联机：一位玩家的直连一直正常，却两次被挤出房间，原因是 Epic 房间服务短暂判定他掉线，房间里所有人的游戏立刻把他移除。

- **直连正常时，Epic 房间服务不能再把人弄掉。** Epic 报告某人掉线、而他的直连还有回应时，不告诉游戏；Epic 之后把他放回房间，游戏完全察觉不到。只有直连连续 `GraceSeconds`（30 秒）没回应，或者他真的离开、被踢，才告诉游戏。对自己也一样。
- **直连玩家按直连心跳判断是否还在**，不再看最近有没有游戏数据：菜单里游戏几乎不发数据，以前这时 Epic 连接一断，30 秒后就会交给游戏，哪怕直连好好的。
- **插件信息不再丢**：实测发现加入者的房间数据会在进房几秒后丢掉房主的插件标记和地址。现在插件读到过的信息会一直有效，直到那个人离开。
- **诊断**：游戏每次把人移出房间，日志都会记下当时直连是否还显示他在玩（`GAME kicks ...`）。

## 日本語

### インストール

1. 下の **`EDF6DirectNet-v0.3.4.zip`** をダウンロードし、すべて任意の場所に展開
2. **`INSTALL.bat`** をダブルクリック（Steam ライブラリから EDF6 を自動で探します。EDFModLoader が無ければ公式版も入ります）
3. Steam からいつも通りゲームを起動

旧版からのアップデート：新しい INSTALL.bat を実行するだけで、設定ファイルはそのまま残ります。**部屋の全員がアップデートしてください**：各自のプラグインが自分のゲームに何を伝えるかを決めます。

### 0.3.4 の変更点

実際の 4 人プレイで見つかった問題：直接接続が正常だったプレイヤーが 2 回部屋から追い出されました。Epic のロビーサービスが一時的にそのプレイヤーを見失い、部屋にいる全員のゲームが即座に外したためです。

- **直接接続が生きている間、Epic のロビーサービスが人を落とせなくなりました。** 誰かが切断扱いになっても直接接続が応答していればゲームには伝えず、Epic が部屋に戻せばゲームは何も気付きません。直接接続が `GraceSeconds`（30 秒）続けて応答しないか、本当に抜けた / キックされたときだけゲームに伝えます。自分自身についても同じです。
- **直接接続のプレイヤーは直接接続のハートビートで判断**します（最近のゲーム通信ではなく）。メニュー中はゲームがほとんど通信しないため、以前は直接接続が正常でも Epic 側の接続が切れると 30 秒後にゲームへ伝わっていました。
- **プラグイン情報が消えなくなりました**：参加者側の部屋データから、入室数秒後にホストのプラグイン印とアドレスが消えることがありました。一度読み取った情報は、そのメンバーが抜けるまで有効です。
- **診断**：ゲームがプレイヤーを部屋から外すたびに、その時点で直接接続がまだそのプレイヤーの接続を示していたかをログに記録します（`GAME kicks ...`）。
