## Install

1. Download **`EDF6DirectNet-v0.3.5.zip`** below and extract all of it anywhere
2. Double-click **`INSTALL.bat`** (finds EDF6 in your Steam library; installs the official EDFModLoader if you have none)
3. Start the game from Steam as usual

Upgrading: just run the new INSTALL.bat; your settings file is kept. Online behaviour is the same as 0.3.4.

## What's new in 0.3.5

A measurement release for "other players see me shooting at air". EDF6 keeps its routine state sync under about 320 kbps and skips less important updates near that budget (the developer's own description), so positions and facing can drift apart on different screens. Before touching that budget we need to know whether the game actually reaches it.

- Every minute the log now has a `TRAFFIC last 60s: ...` line: how much the game itself sends (average and busiest second), to how many players, the average packet size, how much of it is the same data sent to several players, and what the direct link really uses up and down, including what the host relays for others.

Please play a normal session (ideally a busy mission) and share `Mods\Plugins\EDF6DirectNet.log` from the host and one joiner.

## 中文

### 安装

1. 下载下面的 **`EDF6DirectNet-v0.3.5.zip`**，完整解压到任意位置
2. 双击 **`INSTALL.bat`**（自动找到 Steam 里的 EDF6；没有 EDFModLoader 会顺便装上官方版）
3. 从 Steam 正常启动游戏

从旧版升级：直接重新运行 INSTALL.bat，原来的设置文件保留。联机功能与 0.3.4 相同。

### 0.3.5 更新

这是针对“别人看见我打空气”的测量版本。EDF6 会把常规状态同步压在约 320 kbps 以内，接近上限时跳过次要更新（开发商自己的说明），所以不同人屏幕上的位置、朝向会对不上。在动这个上限之前，要先知道游戏到底有没有顶到它。

- 日志每分钟多一行 `TRAFFIC last 60s: ...`：游戏自己发了多少数据（平均值和最忙那一秒）、发给几个人、平均每个包多大、其中多少是发给多个人的同一份数据，以及直连实际占用的上传 / 下载，含房主替别人转发的部分。

请正常打一局（最好是怪多的任务），把房主和一位加入者的 `Mods\Plugins\EDF6DirectNet.log` 发出来。

## 日本語

### インストール

1. 下の **`EDF6DirectNet-v0.3.5.zip`** をダウンロードし、すべて任意の場所に展開
2. **`INSTALL.bat`** をダブルクリック（Steam ライブラリから EDF6 を自動で探します。EDFModLoader が無ければ公式版も入ります）
3. Steam からいつも通りゲームを起動

旧版からのアップデート：新しい INSTALL.bat を実行するだけで、設定ファイルはそのまま残ります。オンライン機能は 0.3.4 と同じです。

### 0.3.5 の変更点

「他の人から見ると自分が空撃ちしている」問題のための計測版です。EDF6 は通常の状態同期を約 320 kbps 以内に抑え、上限に近づくと重要度の低い更新を省きます（開発元の説明）。そのため画面ごとに位置や向きがずれます。この上限に手を入れる前に、ゲームが実際に上限に達しているかを確かめます。

- ログに 1 分ごとに `TRAFFIC last 60s: ...` の行が追加されます：ゲーム自身の送信量（平均と最も多かった 1 秒）、送信先の人数、平均パケットサイズ、複数のプレイヤーへ送った同じデータの割合、直結が実際に使っている上り / 下り（ホストが他の人のために中継した分を含む）。

普段通り 1 回プレイして（できれば敵の多いミッションで）、ホストと参加者 1 人の `Mods\Plugins\EDF6DirectNet.log` を共有してください。
