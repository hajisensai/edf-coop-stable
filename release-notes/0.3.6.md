## Install

1. Download **`EDF6DirectNet-v0.3.6.zip`** below and extract all of it anywhere
2. Double-click **`INSTALL.bat`** (finds EDF6 in your Steam library; installs the official EDFModLoader if you have none)
3. Start the game from Steam as usual

This is the last version you install by hand: from here on the plugin updates itself.

## What's new in 0.3.6

- **Automatic updates.** At game start the plugin asks GitHub for the latest release in the background. When there is a newer one it downloads `EDF6DirectNet.dll`, checks it (the published SHA-256, a real DLL, the release's version inside) and puts it in place of the old one; it runs from the next game start, and the log says `UPDATE installed ...`. The game never waits for it, and nothing changes if GitHub cannot be reached (the request uses the system proxy). `[Update] AutoUpdate=0` in the ini turns it off.
- Each release now also publishes `EDF6DirectNet.dll` and `EDF6DirectNet.dll.sha256` for the updater.
- Includes 0.3.5's `TRAFFIC` log line (how much the game sends against its own bandwidth budget).

### 0.3.6 の変更点

- **自動アップデート。** ゲーム起動時に裏で GitHub の最新リリースを確認します。新しい版があれば `EDF6DirectNet.dll` をダウンロードし、検証（公開された SHA-256 と一致、本物の DLL、中の版番号がリリースと一致）したうえで古い版と置き換えます。次回の起動から有効になり、ログに `UPDATE installed ...` と出ます。ゲームを待たせることはなく、GitHub に接続できなくても何も変わりません（通信はシステムのプロキシ設定に従います）。ini の `[Update] AutoUpdate=0` で無効にできます。
- 各リリースに自動アップデート用の `EDF6DirectNet.dll` と `EDF6DirectNet.dll.sha256` を添付するようになりました。
- 0.3.5 の `TRAFFIC` ログ（ゲームの送信量と、ゲーム自身の帯域上限との比較）を含みます。
