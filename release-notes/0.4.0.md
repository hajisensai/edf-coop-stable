## Install

- **On 0.3.6 with automatic updates on:** nothing to do; the plugin updates itself at the next game start.
- **Otherwise:** download **`EDF6DirectNet-v0.4.0.zip`** below, extract all of it anywhere, double-click **`INSTALL.bat`**, then start the game from Steam as usual.

**Everyone in a room should update:** 0.4.0 speaks a new direct-link protocol. A 0.4.0 player and a 0.3.6-or-older player do not link directly with each other; the game keeps working between them over EOS as before.

## What's new in 0.4.0

A security and robustness release after a full code review.

- **Nobody can take over another player's direct link.** Before, without `Key=`, anyone who knew the host's address could connect as a room member who was not on direct and receive that player's game traffic. Now every plugin player publishes the fingerprint of a per-session key in their own lobby member data, and the host accepts a direct link for player X only after a cookie round trip to the sender's address and a hello signed with the key X published. Players without the plugin can never be claimed. `Key=` still adds a tag on every packet against tampering on the network path.
- **The host can no longer be flooded:** nothing is kept for unverified hellos (no client slots to fill, no reflection), packets routed back to their sender are refused, and a link whose unacknowledged data exceeds 8 MB is dropped instead of growing without limit. Malformed packets are rejected strictly (fuzz-tested).
- **Signed updates.** Each release carries `EDF6DirectNet.dll.sig`, an ECDSA P-256 signature over the version and the DLL's SHA-256, made by the release pipeline. The updater installs nothing whose signature does not verify against the key built into the plugin, and only from this repository.
- **Automatic rollback.** After an update the previous DLL is kept until the new one has run for 20 seconds after the game reaches its title screen. If the game crashes or is killed before that, the next start restores the previous version and never installs the failed one again; quitting normally is no failure. At no moment is there no `EDF6DirectNet.dll`, even if the game is killed mid-update.
- **Automatic updates stay on for ini files without an `AutoUpdate` line**, as in 0.3.6; the log now says so at every start. Add `[Update]` `AutoUpdate=0` to turn them off.
- **Loader:** the package now ships EDFModLoader v1.0.10 with its multithread race fixed (the same fix MultiSlot uses). `INSTALL.bat` replaces an existing loader only if it is exactly the unfixed official one (backed up as `winmm.dll.bak-official`); any other loader is left alone.
- **UPnP:** never removes a mapping that belongs to another device; the plugin's own mapping is removed at the next start that does not host and by `UNINSTALL.bat`; `0.0.0.0` and other unusable router addresses are no longer advertised.
- **Firewall:** `EDF6DirectNet_AllowFirewall.bat` now opens only the configured `ListenPort`; `UNINSTALL.bat` removes the rule (when run as administrator; otherwise it prints the command).
- **Installer:** game folders whose path contains `[` `]` no longer overwrite an existing `winmm.dll`.
- **Settings:** a non-numeric value falls back to the default with a log line instead of becoming 0, `Key = value ; comment` works, and UTF-8 ini files with a BOM are read correctly.

### 安装

- **其他情况：** 下载下面的 **`EDF6DirectNet-v0.4.0.zip`**，完整解压到任意位置，双击 **`INSTALL.bat`**，然后从 Steam 正常启动游戏。

**同一个房间的人都应该更新：** 0.4.0 使用新的直连协议。0.4.0 的玩家和 0.3.6 及更早版本的玩家之间不走直连，游戏照旧通过 EOS 进行。

### 0.4.0 更新

完整代码审查之后的安全与稳定性版本。

- **谁都无法抢走别人的直连。** 以前不设 `Key=` 时，知道房主地址的人可以冒充房间里某个没走直连的成员，收到本该发给那个玩家的游戏数据。现在每个装了插件的玩家都会在自己的大厅成员信息里公布一把本局专用密钥的指纹，房主要先对发送方地址做一次 cookie 往返，再收到用玩家 X 公布的那把密钥签名的 hello，才允许以 X 的身份直连。没装插件的玩家永远不会被冒名。`Key=` 仍然会给每个包加认证标签，防止网络路径上的篡改。
- **房主不会再被灌爆：** 未验证的 hello 不保存任何状态（没有名额可占、也不能拿来反射），发回给发送者自己的转发包被拒绝，某条链路未确认的数据超过 8 MB 就断开，不再无限增长。畸形包一律严格拒收（做过模糊测试）。
- **更新带签名。** 每个发布附带 `EDF6DirectNet.dll.sig`：发布流水线对版本号和 DLL 的 SHA-256 做的 ECDSA P-256 签名。签名对不上插件内置的公钥，或者不是来自本仓库，更新器一律不装。
- **自动回滚。** 更新后旧 DLL 会保留，直到游戏进入标题画面后新版本又运行满 20 秒。在这之前游戏崩溃或被强制结束的话，下次启动会恢复旧版本，并且不再安装失败的版本；正常退出不算失败。即使更新途中游戏被强制结束，`EDF6DirectNet.dll` 也始终存在。
- **ini 里没有 `AutoUpdate` 这一行时，自动更新和 0.3.6 一样保持开启**，日志现在每次启动都会写明。想关闭就加上 `[Update]` `AutoUpdate=0`。
- **加载器：** 安装包现在带的是修复了多线程竞态的 EDFModLoader v1.0.10（与 MultiSlot 相同的修复）。`INSTALL.bat` 只有在已有加载器正好是未修复的官方版时才替换（备份为 `winmm.dll.bak-official`），其他加载器不动。
- **UPnP：** 不会再删除别的设备的映射；插件自己的映射会在之后第一次不做房主的启动时、以及 `UNINSTALL.bat` 时删除；路由器报出的 `0.0.0.0` 等不可用地址不再对外公布。
- **防火墙：** `EDF6DirectNet_AllowFirewall.bat` 现在只放行配置的 `ListenPort`；`UNINSTALL.bat` 会删除这条规则（需要管理员身份，否则打印删除命令）。
- **安装器：** 游戏目录路径里带 `[` `]` 时不会再覆盖已有的 `winmm.dll`。
- **设置：** 非数字的值会回落到默认值并写一行日志，而不是变成 0；支持 `键 = 值 ; 注释`；带 BOM 的 UTF-8 ini 能正确读取。

## 日本語

### インストール

- **0.3.6 で自動アップデートが有効な場合：** 何もしなくて大丈夫です。次回ゲームを起動したときにプラグインが自分で更新します。
- **それ以外：** 下の **`EDF6DirectNet-v0.4.0.zip`** をダウンロードしてすべて任意の場所に展開し、**`INSTALL.bat`** をダブルクリックしてから、Steam からいつも通りゲームを起動してください。

**同じ部屋の全員が更新してください：** 0.4.0 は新しい直結プロトコルを使います。0.4.0 のプレイヤーと 0.3.6 以前のプレイヤーの間は直結せず、ゲームはこれまでどおり EOS 経由で続きます。

### 0.4.0 の変更点

コード全体のレビューを受けた、安全性と安定性のための版です。

- **他の人の直結を乗っ取ることはできなくなりました。** これまでは `Key=` を設定していないと、ホストのアドレスを知っている人が、直結していない部屋のメンバーになりすまして接続し、そのプレイヤー宛てのゲームデータを受け取れました。今はプラグインを入れた各プレイヤーが、このセッション専用の鍵の指紋を自分のロビーメンバー情報に公開し、ホストは送信元アドレスとの cookie の往復と、プレイヤー X が公開した鍵で署名された hello を確認してから、X としての直結を受け入れます。プラグインなしのプレイヤーになりすますことはできません。`Key=` は引き続き、経路上での改ざんを防ぐタグを各パケットに付けます。
- **ホストを大量のパケットで圧迫できなくなりました：** 確認前の hello については何も保持しません（埋められる枠も、反射に使える応答もありません）。送信者自身へ戻る転送は拒否し、未確認のデータが 8 MB を超えたリンクは際限なく増やさずに切断します。不正な形式のパケットは厳密に拒否します（ファジングで確認済み）。
- **署名付きアップデート。** 各リリースには `EDF6DirectNet.dll.sig` が付きます。リリース用パイプラインが版番号と DLL の SHA-256 に付けた ECDSA P-256 署名です。プラグインに組み込まれた公開鍵で署名を確認できないもの、このリポジトリ以外からのものは、一切インストールしません。
- **自動ロールバック。** 更新後、ゲームがタイトル画面に達してから新しい版が 20 秒間動作するまで、前の DLL を残します。それまでにゲームが落ちたり強制終了されたりした場合は次回の起動で前の版に戻し、失敗した版は二度とインストールしません。普通に終了するのは失敗ではありません。更新中にゲームを強制終了しても、`EDF6DirectNet.dll` が無くなる瞬間はありません。
- **ini に `AutoUpdate` の行が無い場合も、0.3.6 と同じく自動アップデートはオンのままです。** 起動のたびにログにその旨が出ます。止めるには `[Update]` `AutoUpdate=0` を追加してください。
- **ローダー：** パッケージには、マルチスレッドの競合を修正した EDFModLoader v1.0.10 を同梱するようになりました（MultiSlot と同じ修正）。`INSTALL.bat` は、既存のローダーが修正前の公式版とまったく同じ場合だけ置き換えます（`winmm.dll.bak-official` にバックアップ）。それ以外のローダーには触れません。
- **UPnP：** 他の機器のマッピングを削除しなくなりました。プラグイン自身のマッピングは、ホストをしない次回の起動時と `UNINSTALL.bat` で削除します。ルーターが返す `0.0.0.0` などの使えないアドレスは公開しません。
- **ファイアウォール：** `EDF6DirectNet_AllowFirewall.bat` は設定した `ListenPort` だけを開けるようになりました。`UNINSTALL.bat` はこの規則を削除します（管理者として実行した場合。それ以外は削除コマンドを表示します）。
- **インストーラー：** パスに `[` `]` を含むゲームフォルダーで、既存の `winmm.dll` を上書きしなくなりました。
- **設定：** 数字でない値は 0 ではなく既定値になり、ログに記録します。`キー = 値 ; コメント` の形も使えます。BOM 付き UTF-8 の ini も正しく読みます。
