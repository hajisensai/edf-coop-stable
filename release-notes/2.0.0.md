## 中文

### 2.0.0：EDF6DirectNet 和 EDF6MultiSlot 合并为 EDF6Coop

- **一个插件代替两个。** 原来的 EDF6DirectNet（直连、防掉线）和 EDF6MultiSlot（8Player MOD 大房间）合成了一个 EDFModLoader 插件 `Mods\Plugins\EDF6Coop.dll`：一份日志 `EDF6Coop.log`（直连相关的行以 `[DN]` 开头），一个设置文件 `EDF6Coop.ini`。
- **升级不用手动操作。** 安装时旧的 `EDF6DirectNet.dll` 和 `EDF6MultiSlot.dll` 会被改名为 `.disabled`，加载器不再加载它们。旧的设置文件保留不删；EDF6Coop 第一次启动时会把旧设置值搬进 `EDF6Coop.ini`。想退回旧版：删掉 `EDF6Coop.dll`，把旧 DLL 名字里的 `.disabled` 去掉。
- **房间人数新增 16p、24p、32p。** 现在有 8p、10p、12p、16p、24p、32p 六种安装包（`EDF6Coop-2.0.0-<人数>p.zip`）。同一个房间的所有人必须用同人数的包。16p、24p、32p 是新加的，目前只用离线幽灵队员验证过，还没有真的这么多人联机测试过；房间越大，房主需要的上传带宽越大。
- **防火墙规则改名为 `EDF6Coop (UDP in)`。** `EDF6Coop_AllowFirewall.bat` 会顺便删掉旧的 `EDF6 DirectNet (UDP in)` 规则，端口从 `EDF6Coop.ini` 读取。
- **自动更新换了发布格式。** 2.0.0 起每种人数单独发布 `EDF6Coop-<人数>p.dll` 和签名；旧版本插件不会自动更新到 2.0.0，请手动安装一次。

## English

### 2.0.0: EDF6DirectNet and EDF6MultiSlot become EDF6Coop

- **One plugin instead of two.** EDF6DirectNet (direct link, drop protection) and EDF6MultiSlot (8Player MOD bigger rooms) are now one EDFModLoader plugin, `Mods\Plugins\EDF6Coop.dll`, with one log, `EDF6Coop.log` (direct-link lines start with `[DN]`), and one settings file, `EDF6Coop.ini`.
- **Upgrading needs no manual steps.** Installing renames the old `EDF6DirectNet.dll` and `EDF6MultiSlot.dll` to `.disabled`, so the loader skips them. The old settings files are kept; on its first start EDF6Coop carries their values into `EDF6Coop.ini`. To go back, delete `EDF6Coop.dll` and remove `.disabled` from the old DLL names.
- **New room sizes: 16p, 24p and 32p.** There are now six packages, 8p, 10p, 12p, 16p, 24p and 32p (`EDF6Coop-2.0.0-<size>p.zip`). Everyone in a room must use the same size. 16p, 24p and 32p are new and have only been checked offline with ghost players, not yet in real online play with that many people; bigger rooms need more upload bandwidth on the host.
- **The firewall rule is now `EDF6Coop (UDP in)`.** `EDF6Coop_AllowFirewall.bat` also removes the old `EDF6 DirectNet (UDP in)` rule and reads the port from `EDF6Coop.ini`.
- **Automatic updates use a new release layout.** From 2.0.0 each room size is published as `EDF6Coop-<size>p.dll` with its signature. Older plugins do not update themselves to 2.0.0: install it once by hand.
