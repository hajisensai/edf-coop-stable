## 中文

### 2.1.0：每个玩家一种 HUD 颜色

- **4 人以上的房间不再撞色。** 游戏的 HUD 只有 4 种玩家颜色（黄、绿、蓝、红），以前 5 号以后的玩家会和 1-4 号重复。现在任务里每个玩家都有自己的颜色，状态灯、聊天气泡、雷达标记三处一致：1-4 号保持游戏原来的颜色，5-8 号是橙、粉、紫、青，以此类推，32 人房每人一种。
- **怎么做到的。** EDF6Coop 会写出 `Mods\HUD\ONLINEHUDTEXTURE.RAB`：游戏自己的 HUD 贴图原样保留，加上一张 32 格的状态灯贴图和 5-32 号的聊天气泡；雷达标记的颜色由插件直接给出。这个文件只在 `[Mission] Extend=1` 时写入；关掉插件或 `Extend=0` 时会被删掉，用回游戏原来的文件。
- **不动别的 MOD。** 如果 `Mods\HUD\ONLINEHUDTEXTURE.RAB` 已经是别的 MOD 的文件，EDF6Coop 不覆盖它，5 号以后的玩家沿用 1-4 号的颜色（和以前一样），日志里会写明。
- **卸载。** 先在 `EDF6Coop.ini` 的 `[MultiSlot]` 里设 `Enabled=0` 并启动一次游戏，这会删掉 MOD 写出的 `Mods\UI\LYT_MAINFRAME.SGO` 和 `Mods\HUD\ONLINEHUDTEXTURE.RAB`，再运行 `UNINSTALL.bat`。

感谢 **FevGrave**：5-8 号的颜色沿用 FevGrave 做的 8 人 HUD 贴图，要改的 HUD 代码也是 FevGrave 找到的。

## English

### 2.1.0: one HUD colour per player

- **No more shared colours above four players.** The game's HUD has four player colours (yellow, green, blue, red), so players 5 and up used to repeat players 1-4. Now every player of a mission has a colour of their own, the same on the status lamp, the chat balloon and the radar marker: players 1-4 keep the game's colours, 5-8 are orange, pink, purple and cyan, and so on, one colour per player up to 32.
- **How.** EDF6Coop writes `Mods\HUD\ONLINEHUDTEXTURE.RAB`: the game's own HUD textures unchanged, plus a 32-lamp status texture and chat balloons for players 5-32; the radar marker colours come from the plugin. The file is written only with `[Mission] Extend=1`; it is removed again when the plugin is disabled or `Extend=0`, and the game's own file is used.
- **Other mods are left alone.** If `Mods\HUD\ONLINEHUDTEXTURE.RAB` already belongs to another mod, EDF6Coop does not overwrite it and players 5 and up share the colours of players 1-4 as before; the log says so.
- **Uninstall.** First set `Enabled=0` in the `[MultiSlot]` section of `EDF6Coop.ini` and start the game once (this removes the files the mod wrote, `Mods\UI\LYT_MAINFRAME.SGO` and `Mods\HUD\ONLINEHUDTEXTURE.RAB`), then run `UNINSTALL.bat`.

Thanks to **FevGrave**: the colours of players 5-8 follow the 8-player HUD textures FevGrave made, and FevGrave found the HUD code to change.
