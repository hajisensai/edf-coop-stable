## 中文

### 2.2.0：房主说了算，Epic 挂了也能回到房间

- **谁在房间里由房主的游戏决定。** 开了直连时，房主把自己游戏里的成员列表经直连发给每个人，大家的游戏都跟着它走。插件自己要告诉游戏的事会先等 5 秒让 Epic 说：Epic 正常时游戏收到的就是 Epic 的事件，和没装插件一样。Epic 和房主都报告同一件事时（比如某人离开）只告诉游戏一次，不会重复进出。
- **不经 Epic 重进房间。** 你从别人的房间掉出来以后 30 分钟内，如果 Epic 搜房失败（房间服务挂了），搜房列表里会出现刚才那个房间。Epic 能搜房时结果原样交给游戏。选它就直接连房主回到房间，不经过 Epic。房主那边看到你的直连回来，房间没满就把你放回房间，其他人也会从房主那里得知。被房主踢出、房间关闭、进了别的房间或房主换人之后，这一项不再出现。
- **踢人照样有效。** 房主踢掉的人不会因为直连还在被放回来；踢一个只在直连上、Epic 不知道的人，由插件直接完成。被踢的人重新经 Epic 进房，就正常放行。
- **需要双方都更新到 2.2.0。** 直连协议从 5 升到 6：2.2.0 和 2.0.0-2.1.0 之间不走直连（游戏照常走 EOS，日志里是 `speaks direct-link protocol 5, we speak 6`）。开着自动更新的话启动游戏就会更新。

不经 Epic 重进目前只用本机测试验证过（直连两端、房间列表、加入 / 离开 / 踢人的流程），还没有在 Epic 真正挂掉时由两台机器实际联机验证过。遇到问题请附 `Mods\Plugins\EDF6Coop.log` 提 Issue，相关的行以 `REJOIN` 和 `ROOM` 开头。

## English

### 2.2.0: the host's say, and back into the room while Epic is down

- **The host's game decides who is in the room.** With the direct link, the host sends its game's member list to everyone over it, and every game follows that list. What the plugin would tell the game first waits 5 s for Epic to say it: while Epic works, the game gets Epic's events, as without the plugin. When Epic and the host report the same thing (someone left, say) the game hears it once, so nobody joins or leaves twice.
- **Back into the room without Epic.** For 30 minutes after you drop out of someone's room, a room search Epic cannot run (its lobby service down) shows that room. A search Epic answers reaches the game as it is. Choosing it connects you straight to the host, without Epic. The host's plugin sees your direct link come back and lets you in again while the room has space, and everyone else hears it from the host. Once the host kicked you, the room closed, you entered another room or the room's host changed, the entry is no longer shown.
- **Kicks still hold.** A player the host kicked is not let back in by a direct link that is still up; kicking a player Epic does not know of is done by the plugin. A kicked player who joins again through Epic is let in as usual.
- **Both sides need 2.2.0.** The direct-link protocol goes from 5 to 6: 2.2.0 and 2.0.0-2.1.0 do not link directly (the game goes on over EOS, and the log says `speaks direct-link protocol 5, we speak 6`). With automatic updates on, starting the game updates it.

Rejoining without Epic has only been verified by local tests so far (both ends of the direct link, the room list, joining, leaving and kicking), not yet by two machines playing together while Epic is actually down. If something goes wrong, open an issue with `Mods\Plugins\EDF6Coop.log`; the relevant lines start with `REJOIN` and `ROOM`.
