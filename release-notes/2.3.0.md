## 中文

### 2.3.0：一个包，房主选人数

- **只有一个安装包。** 以前 8p、10p、12p、16p、24p、32p 各一个包，人数不同的人进不了对方的房间（比如用 8p 的人进不了 32p 的房）。从 2.3.0 起只有 `EDF6Coop-2.3.0.zip`，所有人都装它，每个安装都能容纳 32 人。
- **房主在游戏里选人数。** 在房间外的菜单按 F2 或按下左摇杆，依次切换 OFF → 8 → 10 → 12 → 16 → 24 → 32 → OFF，菜单左下角显示当前选择（例如 `F2/LS 12Player MOD :ON`），保存在 `EDF6Coop.ini` 的 `[MultiSlot] RoomSize`。加入的人什么都不用选，任何人数的房间都能进。
- **搜房**：OFF 时只显示普通 4 人房；ON 时显示所有人数的大房间。以前 8p 版 OFF 时也能看到大房间，现在要找大房间请先按 F2 打开（选几人都行）。
- **旧设置照用。** 原来 `EightPlayerRooms=1`（8Player MOD ON）的人更新后就是 8 人房，下次按 F2 时改写成 `RoomSize`。10p 及以上旧版本的 ON 也会变成 8 人，按 F2 换成你要的人数即可。
- **需要大家都更新到 2.3.0。** 2.3.0 和 2.2.x（任何人数的旧包）互相看不到、进不了对方的大房间。开着自动更新的话，任何人数的 2.2.x 启动一次游戏就会更新到 2.3.0。普通 4 人房照旧谁都能进，包括没装 MOD 的人。

16、24、32 人目前仍只用离线幽灵队员验证过。遇到问题请附 `Mods\Plugins\EDF6Coop.log` 提 Issue。

## 日本語

### 2.3.0：パッケージは1つ、人数はホストが選ぶ

- **パッケージは1つだけになりました。** これまでは 8p・10p・12p・16p・24p・32p で別々のパッケージで、人数の違う人は互いの部屋に入れませんでした（8p の人は 32p の部屋に入れない、など）。2.3.0 からは `EDF6Coop-2.3.0.zip` だけで、全員がこれを入れます。どのインストールも 32 人まで対応します。
- **人数はホストがゲーム内で選びます。** 部屋の外のメニューで F2 か左スティック押し込みで OFF → 8 → 10 → 12 → 16 → 24 → 32 → OFF と切り替わり、メニュー左下に表示されます（例：`F2/LS 12Player MOD :ON`）。`EDF6Coop.ini` の `[MultiSlot] RoomSize` に保存されます。参加する人は何も選ばず、どの人数の部屋にも入れます。
- **部屋検索**：OFF ではいつもの4人部屋だけ、ON では全人数の大きな部屋が出ます。以前の 8p 版は OFF でも大きな部屋が出ましたが、今は大きな部屋を探すときは先に F2 で ON にしてください（人数はどれでも構いません）。
- **古い設定もそのまま使えます。** `EightPlayerRooms=1`（8Player MOD ON）だった人は更新後 8 人部屋になり、次に F2 を押したときに `RoomSize` に書き換わります。10p 以上の古い版の ON も 8 人になるので、F2 で好きな人数に切り替えてください。
- **全員 2.3.0 への更新が必要です。** 2.3.0 と 2.2.x（どの人数の古いパッケージでも）は互いの大きな部屋が見えず、入れません。自動更新が ON なら、どの人数の 2.2.x も一度起動すれば 2.3.0 に更新されます。いつもの4人部屋は今まで通り、MOD を入れていない人とも遊べます。

16・24・32 人は今のところオフラインのゴースト隊員でしか確認していません。問題があれば `Mods\Plugins\EDF6Coop.log` を添えて Issue を作ってください。

## English

### 2.3.0: one package, the host picks the size

- **One package.** Until now there was a package per room size (8p, 10p, 12p, 16p, 24p, 32p), and players with different sizes could not join each other (someone on 8p could not join a 32p room, for one). From 2.3.0 there is only `EDF6Coop-2.3.0.zip`; everyone installs it, and every install holds 32 players.
- **The host picks the size in the game.** Outside a room, F2 or pressing the left stick steps OFF → 8 → 10 → 12 → 16 → 24 → 32 → OFF, shown bottom left of the menu (e.g. `F2/LS 12Player MOD :ON`) and saved as `[MultiSlot] RoomSize` in `EDF6Coop.ini`. Joiners choose nothing and can join a room of any size.
- **Room search**: OFF lists normal 4-player rooms only; ON lists the bigger rooms of every size. The 8p build listed bigger rooms with OFF too; now switch F2 on (any size) to look for one.
- **Old settings carry over.** With `EightPlayerRooms=1` (8Player MOD ON) you host 8-player rooms after the update; the next F2 press writes `RoomSize` instead. ON in a 10p or larger build also becomes 8: press F2 for the size you want.
- **Everyone needs 2.3.0.** 2.3.0 and 2.2.x (a package of any size) neither see nor join each other's bigger rooms. With automatic updates on, 2.2.x of any size updates to 2.3.0 on the next game start. Normal 4-player rooms work with everyone as before, also with players without the mod.

16, 24 and 32 players are still only checked offline with ghost players. If something goes wrong, open an issue with `Mods\Plugins\EDF6Coop.log`.
