## 中文

### 2.3.2：菜单显示版本和更新情况，大房间敌人更多

- **菜单左下角显示 EDF6Coop 的版本和自动更新情况**（在房间外，F2 人数提示后面）：
  - `EDF6Coop 2.3.2 (latest)`：已是最新版；
  - `EDF6Coop 2.3.1 -> 2.3.2 downloaded, restart the game`：新版已下载装好，重启游戏后生效；
  - `EDF6Coop 2.3.2 (updated from 2.3.1)`：这次启动刚从 2.3.1 更新上来；
  - `(update check failed)` 连不上 GitHub，`(update failed, see EDF6Coop.log)` 更新失败，`(auto update off)` 关了自动更新。
- **8 人以上的任务敌人继续增加**：超过 4 人后每多一人敌人数量 +0.2 倍，不再在 8 人 ×1.8 封顶。12 人 ×2.6、16 人 ×3.4、24 人 ×5.0、32 人 ×6.6。敌人耐久和伤害仍按 4 人。人多时主机的帧率压力会明显变大；嫌多可以全员设 `[Mission] ExtraEnemies=0`。
- 9 人以上的房间里，2.3.2 和更早版本算出的敌人数量不同，请大家都更新到 2.3.2（开着自动更新的话启动一次游戏即可）。8 人及以下不受影响。

## 日本語

### 2.3.2：メニューにバージョンと更新状況、大人数で敵が増える

- **メニュー左下に EDF6Coop のバージョンと自動更新の状況を表示します**（部屋の外、F2 の人数表示の後ろ）：
  - `EDF6Coop 2.3.2 (latest)`：最新版です；
  - `EDF6Coop 2.3.1 -> 2.3.2 downloaded, restart the game`：新しい版をダウンロード済み、ゲーム再起動で有効；
  - `EDF6Coop 2.3.2 (updated from 2.3.1)`：今回の起動で 2.3.1 から更新されました；
  - `(update check failed)` GitHub に接続できない、`(update failed, see EDF6Coop.log)` 更新失敗、`(auto update off)` 自動更新 OFF。
- **8人を超えるミッションでも敵が増え続けます**：4人を超える1人ごとに敵の数が 0.2倍ずつ増え、8人 1.8倍で止まらなくなりました。12人 2.6倍、16人 3.4倍、24人 5.0倍、32人 6.6倍。敵の耐久とダメージは4人のままです。人数が多いとホストのフレームレート負荷がかなり増えます。多すぎる場合は全員 `[Mission] ExtraEnemies=0` にしてください。
- 9人以上の部屋では 2.3.2 とそれより前の版で敵の数が変わるので、全員 2.3.2 に更新してください（自動更新 ON なら一度起動するだけ）。8人以下は影響ありません。

## English

### 2.3.2: version and updates in the menu, more enemies in big rooms

- **The lower left of the menu shows EDF6Coop's version and what its automatic update did** (outside a room, after the F2 room size):
  - `EDF6Coop 2.3.2 (latest)`: nothing newer;
  - `EDF6Coop 2.3.1 -> 2.3.2 downloaded, restart the game`: the new version is installed and runs after a restart;
  - `EDF6Coop 2.3.2 (updated from 2.3.1)`: this start is the update from 2.3.1;
  - `(update check failed)` GitHub could not be reached, `(update failed, see EDF6Coop.log)` the update failed, `(auto update off)` automatic updates are off.
- **Enemy counts keep growing past eight players**: x0.2 more for every player above four, no longer stopping at eight's x1.8. 12 x2.6, 16 x3.4, 24 x5.0, 32 x6.6. Enemy durability and damage stay at the 4-player values. Big rooms cost the host noticeably more frame time; to keep the original counts, everyone sets `[Mission] ExtraEnemies=0`.
- In rooms of nine or more, 2.3.2 and earlier versions create different enemy counts: everyone should update to 2.3.2 (with automatic updates on, starting the game once does it). Eight players or fewer are not affected.
