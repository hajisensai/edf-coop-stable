# EDF6Coop 2.5.0

## 中文

此版本将此前仅在主线构建中提供的联机重写和修复正式发布。

- 修复扩容后语音 HUD 数组的大块内存分配/释放不匹配，解决相关的关卡结束闪退。
- 更新网络传输、分片、流量分类、优先级预算及多路径处理；修复退出或切换会话后遗留接收状态的问题。
- 改进玩家、敌人及命中权威处理，包括无驾驶员载具的房主结算与攻击者弱引用生命周期。
- 武器数据默认在下载前询问；一个不可达成员不再阻塞其他成员的文件传输，过期确认不会套用到新会话。旧正式版的 `Accept=Always` 按 `Ask` 处理，需要自动接受时可显式设置 `Accept=Auto`。
- 大房间实现上限扩展至 1024，F2 可选择 8、10、12、16、24、32、48、64、128、256、512、1024；超过 16 人时没有游戏内语音。

**升级要求：** MOD 房间全员使用同一版本。2.5.0 的扩容房间与旧正式版 2.4.x 的槽位布局及网络协议不兼容，请整组升级。普通四人模式仍可用。

**验证边界：** 1024 是实现上限，不代表已经验证该人数能够实际游玩。本次发布使用真实游戏菜单/HUD资源，通过原生补丁、插件加载及网络自动化测试；没有新增大规模真实多人实战验证。

下载 `EDF6Coop-2.5.0.zip`，退出游戏后完整解压并运行 `INSTALL.bat`。自动更新使用同仓库签名的 DLL；保留旧人数版 DLL 名称，让旧安装也能升级。已有设置按插件迁移规则保留。

## English

This release publishes the networking rewrite and fixes previously available only in main-branch builds.

- Fix the enlarged voice-HUD vector's allocation/deallocation contract and the associated mission-end crash.
- Update transport, fragmentation, traffic classes, bandwidth priorities and multipath handling; discard receive state at session boundaries.
- Improve player/enemy and hit authority, including host authority for driverless vehicles and attacker weak-reference ownership.
- Ask before downloading shared weapon data by default. Unreachable peers no longer block other transfers, and stale consent does not carry into a new session. Legacy `Accept=Always` is treated as `Ask`; use `Accept=Auto` to opt into automatic acceptance.
- Extend the implemented room limit to 1024. F2 offers 8/10/12/16/24/32/48/64/128/256/512/1024. Rooms above 16 have no in-game voice chat.

Everyone in a modded room must update together: expanded rooms are not compatible with the older official 2.4.x slot layout/protocol. Normal four-player mode remains available. The 1024 limit is not a demonstrated practical multiplayer capacity; large-scale live play has not been newly verified. Packages use real game assets, with native-code and automated network checks.

Extract `EDF6Coop-2.5.0.zip` and run `INSTALL.bat` while the game is closed. Signed auto-update assets are included under the current and legacy room-size filenames.

## 日本語

main ブランチで提供していた通信の再構成と修正を正式公開します。拡張された音声 HUD 配列の確保・解放を修正し、関連するミッション終了時のクラッシュに対応しました。通信の分割・優先度・複数経路、セッション切り替え、プレイヤー・敵・命中の権限処理も改善しています。

武器データは既定で取得前に確認します。到達できない相手が他の転送を止めず、古い確認結果を新しい部屋に適用しません。旧 `Accept=Always` は `Ask` として扱い、自動承認は `Accept=Auto` で指定します。

実装上の人数上限は 1024 です。F2 の選択肢は 8/10/12/16/24/32/48/64/128/256/512/1024、16人超ではゲーム内音声を使用しません。1024人での実プレイを保証するものではなく、大規模な実戦検証は未実施です。MOD 部屋は全員同じ版に更新してください。旧正式版 2.4.x の拡張部屋とは互換ではありません。

ゲームを終了し、ZIP を全部展開して `INSTALL.bat` を実行してください。自動更新用 DLL には署名が付き、旧人数版の名前も引き続き提供します。
