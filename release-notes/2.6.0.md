# EDF6Coop 2.6.0

## 中文

此版本发布 2.5.0 之后主线上的全军出击（EDF6 All Forces）联机配套与房间修复。

- 新增给扩展插件用的两套带版本号的 C 接口：`EDF6CoopGetExtensionApi`（经认证、有序的扩展消息通道）和 `EDF6CoopGetMemberAttributeApi`（房间成员属性）。全军出击的多人支援功能需要后者，2.5.0 没有。
- 全军出击房间使用独立的房间类型，支援功能只在当前世界里已准入的玩家之间生效；EOS 大厅暂时读不到已确认的扩展属性时，同一身份的支援能力不再丢失；切换房间后不再带着旧房间的房主权限。
- 房主的位次表、踢人名单和全军出击世界状态改为也经 EOS P2P 发送，装了全军出击的玩家加入没有直连的房主时不再约 10 秒后报「无法参加房间」。加入、重连和满员回退时会核对全军出击的任务包。
- 认证直连仍然正常时，游戏原生超时不再自动踢人或让客户端离房。
- 转发的命中带上子命中，客机能打到只认弱点的目标（如母舰核心）。

**升级要求：** 网络协议从 2 升到 3。MOD 房间全员必须同时使用 2.6.0，房主会移除协议不同的成员；2.5.0 及更早版本的客人也进不了 2.6.0 房主的全军出击房间。全军出击的多人支援功能要求全员 EDF6Coop 2.6.0 及以上。普通四人模式不受影响。

**验证边界：** 离线测试与不开游戏的联机测试（GameNet）全部通过，原生补丁对照本机 EDF.dll 校验通过；没有做真实双机联机实测，尤其是在 EOS 线程上收 P2P 包、弱点命中转发这两项还需要实机确认。

下载 `EDF6Coop-2.6.0.zip`，退出游戏后完整解压并运行 `INSTALL.bat`。开着自动更新的话，启动一次游戏就会下载，下次启动生效。

## English

This release ships the All Forces (EDF6 All Forces) multiplayer support and room fixes merged since 2.5.0.

- Two versioned C ABIs for extension plugins: `EDF6CoopGetExtensionApi` (an authenticated, ordered extension channel) and `EDF6CoopGetMemberAttributeApi` (room member attributes). All Forces' multiplayer support needs the latter, which 2.5.0 lacks.
- All Forces rooms have their own room type and support is gated on the players admitted to the current world. A verified support capability survives EOS lobby attributes briefly disappearing, and host-only state no longer carries over into the next room.
- The host's member slots, kick list and All Forces world state also go over EOS P2P, so All Forces players no longer fail to join ("could not join the room" after about 10 s) a host without a direct link. Rejoin, virtual-room and full-room paths check All Forces' mission pack.
- The game's own timeout no longer kicks a member or leaves the room while the authenticated direct link is healthy.
- Forwarded hits carry their sub-hits, so clients can damage weak-point-only targets (such as mothership cores).

Network protocol 2 → 3: everyone in a modded room must run 2.6.0; the host removes members on another protocol, and 2.5.0 or older clients cannot join a 2.6.0 host's All Forces room. All Forces' multiplayer support requires EDF6Coop 2.6.0+ for everyone. Normal four-player mode is unaffected. Offline tests and the game-less network harness (GameNet) pass and the native patches check against EDF.dll; this has not been verified in a live two-machine session.

Extract `EDF6Coop-2.6.0.zip` and run `INSTALL.bat` while the game is closed, or let the auto-updater fetch it.

## 日本語

2.5.0 以降に main へ入った全軍出撃（EDF6 All Forces）向けの連携と部屋まわりの修正を公開します。拡張プラグイン向けに、認証付きで順序が保証される拡張通信 `EDF6CoopGetExtensionApi` と部屋メンバー属性 `EDF6CoopGetMemberAttributeApi` の C インターフェースを追加しました。全軍出撃のマルチプレイ支援には後者が必要です。

ホストのメンバー順・キック一覧・全軍出撃のワールド状態は EOS P2P でも送るため、直結のないホストの部屋にも全軍出撃を入れたまま参加できます。認証済みの直結が生きている間はゲーム本来のタイムアウトでキック・退出しません。転送された命中にサブ命中を含め、弱点だけが有効な敵（母艦のコアなど）にもクライアントから攻撃が通ります。

通信プロトコルは 2 から 3 になりました。MOD 部屋は全員 2.6.0 に更新してください。ホストはプロトコルの違うメンバーを外します。全軍出撃のマルチプレイ支援には全員 EDF6Coop 2.6.0 以上が必要です。オフラインテストとゲームなしの通信テストは通過していますが、実機 2 台での検証はしていません。

ゲームを終了し、ZIP を全部展開して `INSTALL.bat` を実行してください。自動更新でも取得できます。
