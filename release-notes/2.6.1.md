# EDF6Coop 2.6.1

## 中文

此版本发布 2.6.0 之后主线上的扩展传输容量接口，全军出击（EDF6 All Forces）的「操控性物品」联机需要它。

- 新增两个可选、带版本号的 C 接口：`EDF6CoopGetExtensionCapacity`（只读查询本机扩展通道的容量：单条载荷上限、对端数、收件箱条数、待确认字节上限、拥塞阈值）和 `EDF6CoopTrySendExtension`（有界、原子的发送：超过调用方给的待确认字节 / 包数上限时返回「稍后再试」，不消耗序号、不断开扩展会话）。原有的 `EDF6CoopGetExtensionApi`（40 字节，版本 1）不变。
- 扩展通道的收件箱从 256 条放宽到 4096 条，待确认数据上限从 256 KB 放宽到 1 MB；链路一时拥塞不再让扩展会话重置，改为按真实的待确认队列做准入。

**兼容性：** 网络协议没有变化（仍是 3，线上报文格式未改），2.6.0 与 2.6.1 可以在同一 MOD 房间联机。但「操控性物品」等依赖新接口的全军出击功能需要本机 2.6.1；房间里仍是 2.6.0 的成员收件箱只有 256 条，大量扩展消息可能让该成员的扩展会话重置，因此建议全员更新到 2.6.1。普通四人模式不受影响。

**验证边界：** 离线测试全部通过（含新增的扩展传输容量 / 有界发送测试）；本次未对照 EDF.dll 重跑需要游戏文件的原生补丁校验与 GameNet 联机测试（此版未改原生补丁与房间代码），也没有做真实双机联机实测。

下载 `EDF6Coop-2.6.1.zip`，退出游戏后完整解压并运行 `INSTALL.bat`。开着自动更新的话，启动一次游戏就会下载，下次启动生效。

## English

This release ships the extension transport capacity ABI merged since 2.6.0, which All Forces' (EDF6 All Forces) controllable items need online.

- Two optional, versioned C ABIs: `EDF6CoopGetExtensionCapacity` (a read-only query of the local extension channel's limits: maximum payload, peers, inbox messages, pending bytes, congestion threshold) and `EDF6CoopTrySendExtension` (bounded, atomic admission: above the caller's pending byte / packet limit it returns WOULD_BLOCK without using a sequence number or resetting the extension session). The existing 40-byte `EDF6CoopGetExtensionApi` version 1 is unchanged.
- The extension inbox grows from 256 to 4096 messages and the pending limit from 256 KB to 1 MB; a briefly congested link no longer resets the extension session, admission measures the real pending queue instead.

The network protocol is unchanged (still 3, same wire format): 2.6.0 and 2.6.1 play together in a modded room. All Forces features that use the new ABI (controllable items) need 2.6.1 locally, and a 2.6.0 member's 256-message inbox can reset its extension session under heavy extension traffic, so everyone should update to 2.6.1. Normal four-player mode is unaffected. Offline tests pass, including the new capacity / bounded-send tests; the tests that need the game's EDF.dll (native patch checks, GameNet) were not re-run for this release, which changes neither the native patches nor the room code, and it has not been verified in a live two-machine session.

Extract `EDF6Coop-2.6.1.zip` and run `INSTALL.bat` while the game is closed, or let the auto-updater fetch it.

## 日本語

2.6.0 以降に main へ入った拡張通信の容量インターフェースを公開します。全軍出撃（EDF6 All Forces）の「操作できるアイテム」のオンラインプレイに必要です。拡張プラグイン向けに、容量を読み取る `EDF6CoopGetExtensionCapacity` と、上限を超えると「後で再試行」を返して通信を切らない `EDF6CoopTrySendExtension` を追加しました。既存の `EDF6CoopGetExtensionApi`（バージョン 1）は変わりません。拡張通信の受信箱は 256 件から 4096 件、未確認データの上限は 256 KB から 1 MB に広がりました。

通信プロトコルは変わっていません（3 のまま）。2.6.0 と 2.6.1 は同じ MOD 部屋で遊べますが、新しいインターフェースを使う全軍出撃の機能には 2.6.1 が必要で、2.6.0 のメンバーは拡張メッセージが多いと拡張通信がリセットされることがあるため、全員 2.6.1 への更新をおすすめします。オフラインテスト（新しい容量・送信上限のテストを含む）は通過しています。EDF.dll が必要なテスト（ネイティブパッチ照合、GameNet）はこの版では再実行しておらず（ネイティブパッチと部屋のコードは変更なし）、実機 2 台での検証もしていません。

ゲームを終了し、ZIP を全部展開して `INSTALL.bat` を実行してください。自動更新でも取得できます。
