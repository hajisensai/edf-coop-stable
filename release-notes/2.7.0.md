# EDF6Coop 2.7.0

## 中文

此版本是新版全军出击（EDF6 All Forces，会公开自己房间协议的版本）的联机配套，并修复加入房间与房间画面的问题。

- **全军出击房间协议：** EDF6Coop 不再自己写死全军出击的房间前缀和 `AF_PROFILE`，改为从全军出击本身读取（`EDF6AF_RoomPrefix` / `EDF6AF_RoomProfile`）。新版全军出击的房间（协议 2）需要 2.7.0。
- **旧版全军出击照旧可用：** 没有这两个导出的全军出击（到目前为止发布的所有版本，协议 1）仍按 2.6.1 的方式工作，旧版之间的房间照常联机。新旧全军出击的房间协议不同，不能同房；想一起玩请全员更新全军出击。
- **被拒绝时有提示：** EDF6Coop 拒绝加入它记住的房间（REJOIN、经直连进房、满员回退）时，菜单左下会显示约 30 秒原因，例如「Room refused: host's All Forces is newer, update All Forces」（房主的全军出击更新，请更新全军出击）或「... is older」（房主的全军出击更旧）。任务包不符时仍由全军出击自己弹窗说明。
- **加入房间：** 加入通过 EOS 发送位次表的房主的房间时，不再等 45 秒后失败（2026-10-24 的玩家反馈，全军出击客人）；等待期间房间被关闭会让加入失败，而不是进入已关闭的房间。
- **房间画面：** 每位成员一个面板，5 人以上自动缩小排布（18 人起分两列），最多显示 32 人；取消了原来每页 4 人的翻页（F3 / Tab / 右摇杆）。开了全军出击 PvP 时每行显示该成员的阵营。

**兼容性：** 网络协议没有变化（仍是 3），2.6.0、2.6.1 与 2.7.0 可以在同一 MOD 房间联机，普通四人模式不受影响。全军出击房间由全军出击的版本决定：新版全军出击需要 2.7.0；旧版全军出击用 2.7.0 或 2.6.1 都只进旧版之间的房间。

**验证边界：** `build.ps1 -Test` 全部通过（106 项，含对照本机 EDF.dll 的原生补丁校验与不开游戏的联机测试 GameNet）；新增的测试覆盖未装全军出击、旧版全军出击（无导出）和新版全军出击（有导出）三种情况。没有做真实双机联机实测，菜单左下的拒绝提示与新的房间画面排布也还没在实机上确认。

下载 `EDF6Coop-2.7.0.zip`，退出游戏后完整解压并运行 `INSTALL.bat`。开着自动更新的话，启动一次游戏就会下载，下次启动生效。

## English

This release goes with the new All Forces (EDF6 All Forces) builds that publish their own room protocol, and fixes room joins and the room screen.

- **All Forces room protocol:** EDF6Coop no longer keeps its own copy of All Forces' room prefix and `AF_PROFILE`; it reads them from All Forces (`EDF6AF_RoomPrefix` / `EDF6AF_RoomProfile`). Rooms of the new All Forces (protocol 2) need 2.7.0.
- **Older All Forces keeps working:** an All Forces without those exports (every release so far, protocol 1) works as it did with 2.6.1, and its players keep their rooms with each other. The two All Forces generations use different room protocols and cannot share a room; update All Forces to play together.
- **Refusals are shown:** when EDF6Coop refuses a room it remembered (REJOIN, the direct-link entry, the full-lobby fallback), the lower left of the menu says why for about 30 s, e.g. "Room refused: host's All Forces is newer, update All Forces" or "... is older". A mission pack mismatch is still explained by All Forces' own dialog.
- **Joining:** joining a room whose host sends its member slots over EOS no longer waits 45 s and fails (player reports of 2026-10-24, All Forces guests); a room closed while the join waits fails the join instead of entering a closed room.
- **Room screen:** one panel per member, laid out smaller from five members (two columns from 18), up to 32 shown; the four-per-page paging (F3 / Tab / right stick) is gone. With All Forces' PvP on, each row shows the member's faction.

The network protocol is unchanged (still 3): 2.6.0, 2.6.1 and 2.7.0 play together in a modded room, and normal four-player mode is unaffected. All Forces rooms follow the All Forces version: the new All Forces needs 2.7.0; an older All Forces, with 2.7.0 or 2.6.1, joins only older All Forces rooms. `build.ps1 -Test` passes (106 tests, including the native patch checks against EDF.dll and the game-less network harness GameNet); new tests cover no All Forces, an older All Forces without the exports and a new one with them. It has not been verified in a live two-machine session, and the menu notice and the new room screen layout have not been checked in the running game.

Extract `EDF6Coop-2.7.0.zip` and run `INSTALL.bat` while the game is closed, or let the auto-updater fetch it.

## 日本語

部屋プロトコルを自分で公開する新しい全軍出撃（EDF6 All Forces）と組み合わせる版です。部屋への参加と部屋画面の問題も直しています。

- **全軍出撃の部屋プロトコル：** EDF6Coop は全軍出撃の部屋プレフィックスと `AF_PROFILE` を自分で持たず、全軍出撃から読み取ります（`EDF6AF_RoomPrefix` / `EDF6AF_RoomProfile`）。新しい全軍出撃（プロトコル 2）の部屋には 2.7.0 が必要です。
- **古い全軍出撃もそのまま使えます：** この 2 つのエクスポートがない全軍出撃（これまでに公開されたすべての版、プロトコル 1）は 2.6.1 と同じように動き、古い版どうしの部屋で遊べます。新旧の全軍出撃は部屋プロトコルが違うので同じ部屋には入れません。一緒に遊ぶには全軍出撃を更新してください。
- **拒否の理由を表示：** EDF6Coop が記憶した部屋（REJOIN、直結での入室、満員時の代替経路）への参加を拒否すると、メニュー左下に 30 秒ほど理由が出ます（例：「Room refused: host's All Forces is newer, update All Forces」、「... is older」）。ミッションパックの不一致は今までどおり全軍出撃のダイアログが説明します。
- **部屋への参加：** EOS でメンバーの席順を送るホストの部屋に入るとき、45 秒待って失敗することがなくなりました（2026-10-24 のプレイヤー報告、全軍出撃のゲスト）。待っている間に部屋が閉じられたら、閉じた部屋に入らず参加が失敗します。
- **部屋画面：** メンバーごとに 1 枚の欄を表示し、5 人以上は小さく並べ（18 人から 2 列）、最大 32 人まで表示します。1 ページ 4 人のページ切り替え（F3 / Tab / 右スティック）はなくなりました。全軍出撃の PvP が有効なときは各行に陣営を表示します。

通信プロトコルは変わっていません（3 のまま）。2.6.0、2.6.1、2.7.0 は同じ MOD 部屋で遊べ、通常の 4 人モードにも影響はありません。全軍出撃の部屋は全軍出撃の版で決まります。新しい全軍出撃には 2.7.0 が必要で、古い全軍出撃は 2.7.0 でも 2.6.1 でも古い版どうしの部屋にだけ入ります。`build.ps1 -Test` はすべて通過しています（106 件。EDF.dll と照合するネイティブパッチのテストと、ゲームを起動しない通信テスト GameNet を含みます）。全軍出撃なし・エクスポートのない古い全軍出撃・エクスポートのある新しい全軍出撃の 3 通りを新しいテストで確認しています。実機 2 台での検証はしておらず、メニュー左下の拒否表示と新しい部屋画面の配置もゲーム内では未確認です。

ゲームを終了し、ZIP を全部展開して `INSTALL.bat` を実行してください。自動更新でも取得できます。
