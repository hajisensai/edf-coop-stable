# EDF6Coop 2.8.0

## 中文

此版本让插件联机通道在拥塞后自动恢复，并加快收包（[#47](https://github.com/hajisensai/edf-coop-stable/pull/47)）。

- **拥塞后自动恢复：** 以前插件扩展通道的积压超过上限（1 MiB / 8192 包）或收件箱超过 4096 条，本房间余下时间插件联机全部失效（全军出击的支援、指挥、怪物操控等整关不再同步）。现在溢出只算一次短暂断开：通道换代、丢弃排队消息，链路积压降到一半以下后自动恢复。
- **批量收包：** 新增 `EDF6CoopPollExtensionBatch`，插件一次加锁取一批消息，不再每条消息各拿一次网络锁。

**兼容性：** 网络协议没有变化（仍是 3），2.6.0 至 2.8.0 可在同一 MOD 房间联机。**新版全军出击联机需要 EDF6Coop 2.8.0**，装旧版 EDF6Coop 时全军出击会拒绝建房 / 进房并提示升级。普通四人模式不受影响。

下载 `EDF6Coop-2.8.0.zip`，退出游戏后完整解压并运行 `INSTALL.bat`。开着自动更新的话，启动一次游戏就会下载，下次启动生效。

## English

This release lets the plugin network channel recover from congestion by itself and polls it faster ([#47](https://github.com/hajisensai/edf-coop-stable/pull/47)).

- **Recovery after congestion:** an extension backlog over the ceiling (1 MiB / 8192 packets) or an inbox over 4096 messages used to end plugin networking for the rest of the room. Now an overflow is a short readiness blip: the channel starts a new generation, drops queued messages, and becomes ready again once the links drain to half the ceiling.
- **Batch poll:** the new `EDF6CoopPollExtensionBatch` lets a plugin take a batch of messages under one lock instead of one lock per message.

**Compatibility:** the network protocol is unchanged (still 3), so 2.6.0 to 2.8.0 play together in a modded room. **The new All Forces needs EDF6Coop 2.8.0 for online play**; with an older EDF6Coop it refuses to create or join rooms and asks you to update. Normal four-player mode is unaffected.

Extract `EDF6Coop-2.8.0.zip` and run `INSTALL.bat` while the game is closed, or let the auto-updater fetch it.

## 日本語

プラグイン通信チャンネルが混雑から自動で回復するようになり、受信も速くなりました（[#47](https://github.com/hajisensai/edf-coop-stable/pull/47)）。

- **混雑後の自動回復：** これまでは拡張チャンネルの滞留が上限（1 MiB / 8192 パケット）を超えるか受信箱が 4096 件を超えると、その部屋では以後プラグイン通信が止まったままでした。今後は短い切断として扱い、世代を更新して滞留分を捨て、回線の滞留が半分以下に下がると自動で再開します。
- **一括受信：** 新しい `EDF6CoopPollExtensionBatch` で、メッセージごとではなく一度のロックでまとめて受け取れます。

**互換性：** 通信プロトコルは変わっていません（3 のまま）。2.6.0 から 2.8.0 までは同じ MOD 部屋で遊べます。**新しい全軍出撃のオンラインには EDF6Coop 2.8.0 が必要**で、古い EDF6Coop では部屋の作成・参加を断り、更新を案内します。通常の 4 人モードには影響しません。

ゲームを終了し、`EDF6Coop-2.8.0.zip` を全部展開して `INSTALL.bat` を実行してください。自動更新でも取得できます。
