# EDF6Coop 2.9.0

## 中文

此版本给插件联机通道加上「状态类」消息，并让插件消息不再排在游戏流量后面。

- **状态类消息：** 新增 `sendState`（扩展接口 ABI 2）。适合每帧刷新、只要最新值的数据（全军出击的怪物操控姿态、重力枪、终极打击的持续状态）：不重传，同一 key 只保留最新一份，过时的直接丢弃。
- **插件消息独立排序：** 插件消息改用自己的有序通道。游戏流量丢包重传时，插件消息不再跟着排队等待。

**兼容性：** 直连协议升到 8，网络协议升到 4，2.9.0 不和更早的版本直连，也不一起跑新网络代码。全员都要更新到 2.9.0。**新版全军出击联机需要 EDF6Coop 2.9.0**，装旧版 EDF6Coop 时全军出击会拒绝建房 / 进房并提示升级。

下载 `EDF6Coop-2.9.0.zip`，退出游戏后完整解压并运行 `INSTALL.bat`。开着自动更新的话，启动一次游戏就会下载，下次启动生效。

## English

This release adds state messages to the plugin network channel and stops plugin messages from waiting behind game traffic.

- **State messages:** the new `sendState` (extension ABI 2) is for data refreshed every frame where only the latest value matters (All Forces' controlled-monster poses, gravity gun, ultimate strikes): never retransmitted, only the latest per key is kept, and stale ones are dropped.
- **Plugin messages ordered on their own:** plugin messages use an ordered channel of their own, so a lost and resent game packet no longer holds them up.

**Compatibility:** direct-link protocol 8 and network protocol 4: 2.9.0 makes no direct link with, and runs no new netcode alongside, older versions. Everyone needs 2.9.0. **The new All Forces needs EDF6Coop 2.9.0 for online play**; with an older EDF6Coop it refuses to create or join rooms and asks you to update.

Extract `EDF6Coop-2.9.0.zip` and run `INSTALL.bat` while the game is closed, or let the auto-updater fetch it.

## 日本語

プラグイン通信チャンネルに「状態」メッセージを追加し、プラグインのメッセージがゲームの通信の後ろで待たされないようにしました。

- **状態メッセージ：** 新しい `sendState`（拡張 ABI 2）は、毎フレーム更新され最新値だけが必要なデータ（全軍出撃の操作中の怪物の姿勢、重力銃、必殺技の継続状態）向けです。再送せず、キーごとに最新の 1 件だけを残し、古いものは捨てます。
- **プラグインメッセージの独立した順序：** プラグインのメッセージは専用の順序付きチャンネルを使うため、ゲームのパケットの再送待ちに巻き込まれません。

**互換性：** 直結プロトコル 8、通信プロトコル 4 です。2.9.0 はそれより古い版とは直結せず、新しいネットコードも一緒に動かしません。全員 2.9.0 に更新してください。**新しい全軍出撃のオンラインには EDF6Coop 2.9.0 が必要**で、古い EDF6Coop では部屋の作成・参加を断り、更新を案内します。

ゲームを終了し、`EDF6Coop-2.9.0.zip` を全部展開して `INSTALL.bat` を実行してください。自動更新でも取得できます。
